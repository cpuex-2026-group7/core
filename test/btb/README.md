# BTB 単体テスト

Verilator と C++ ビルド環境がある WSL/Linux で、リポジトリ直下から実行します。

```sh
make -C test/btb
```

成功すると `PASS: BTB (... checks)` が表示されます。不一致やタイムアウトは
`$fatal` で異常終了します。波形は `test/btb/btb.vcd` に出力します。

`test_btb.sv` の `initial` がテストの手順です。`apply_cycle` で同期入力を
立ち下がりに設定し、次の立ち上がりで DUT に取り込ませます。
`check_lookup` は PC を設定し、組み合わせ回路の評価後に期待値と比較します。
`!==` による比較で、未確定値 X も失敗として検出します。

確認する動作:

- 初回リセットと、登録済みの全エントリのリセット
- 更新無効時の未登録・既存エントリの保持
- 登録、ヒット、未登録 index のミス、タグ不一致
- 異なる index の独立性
- 同じ PC の分岐先の更新
- 同じ index の別タグによる置き換え
- 全 index の登録と読み出し（分岐先 0 を含む）
- リセットと更新が同時のときのリセット優先
- リセット後の再登録
